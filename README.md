# Cybersecurity Learning Journal

This repository serves as my personal journal, where I keep track of and document the things I do to improve my knowledge and skills in cybersecurity.

It contains my certifications, personal projects developed to experiment with different concepts and gain hands-on experience, practical labs, cybersecurity job simulations, and technical write-ups documenting my learning along the way.

My aim is to continuously develop my skills, gain practical experience, and challenge myself by exploring both the offensive and defensive sides of cybersecurity, along with other areas of the field.

## Repository Structure

| Folder | Purpose |
|---|---|
| `notes/` | Cybersecurity concepts, study notes and technical references. |
| `hands-on-labs/` | Practical exercises, lab documentation and findings. |
| `personal-projects/` | Projects independently developed to apply and experiment with cybersecurity concepts. |
| `simulations/` | Cybersecurity job simulations and related work. |
| `achievements/` | Certifications and learning milestones. |
